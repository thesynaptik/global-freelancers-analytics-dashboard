# Freelancers Performance Dashboard

## Overview
This project analyzes global freelancer performance using Power BI. The dashboard highlights hourly rates, skills, experience levels, countries, languages, and freelancer activity.

## Files
- `Data Management.pbix` – Power BI dashboard file
- `global_freelancers_raw.csv` – Raw freelancer dataset
- Dashboard screenshot – Preview of the report

## Dataset Columns
The dataset contains:
- Freelancer ID
- Name
- Gender
- Age
- Country
- Language
- Primary Skill
- Years of Experience
- Hourly Rate (USD)
- Rating
- Active Status
- Client Satisfaction

## Dashboard Features
- Average hourly rate
- Average years of experience
- Total number of freelancers
- Highest hourly rate by skill
- Hourly rate by experience level
- Hourly rate by language
- Experience level count by rate category
- Filters for country and gender

## Key Insights
- Average hourly rate: **47.01 USD**
- Average years of experience: **10.66**
- Total freelancers analyzed: **912**
- Top skills by hourly rate include DevOps, Web Development, Blockchain Development, Mobile Apps, and UI/UX Design.

## Tools Used
- Power BI
- CSV dataset
- Data cleaning and visualization

## How to Use
1. Download or clone this repository.
2. Open `Data Management.pbix` in Power BI Desktop.
3. Make sure `global_freelancers_raw.csv` is available in the same project folder.
4. Refresh the data if needed.
5. Explore the dashboard using slicers and filters.

## Project Goal
The goal of this project is to understand freelancer performance trends across countries, skills, languages, and experience levels.
